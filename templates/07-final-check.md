# 7. Final check (before delivery)

Watch every export once, start to finish, on a phone, with sound.

## Each export
- [ ] Hook grabs attention in the first 3 seconds
- [ ] Every spoken word matches the script
- [ ] Brand and product names pronounced and spelled right
- [ ] Captions in sync and readable on a phone
- [ ] No black, flash or frozen frames
- [ ] Product looks the same in every shot; label correct
- [ ] Only approved claims, said and shown
- [ ] CTA and offer text exactly as approved
- [ ] Nothing important hidden behind platform buttons
- [ ] Right size (1080×1920) and length

## File names
`[brand]_[format]_[hook number]_[version].mp4` — e.g. `brewbright_street-interview_H2_v1.mp4`

## After delivery
Add anything that went wrong (or nearly did) to the **mistakes log**.
