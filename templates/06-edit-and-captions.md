# 6. Edit & captions

## Edit order
1. Lay clips in script order: hook → body → CTA.
2. Cut tight: remove pauses longer than about half a second unless they're on purpose.
3. Match the reference breakdown's pacing (first 3 seconds especially).
4. Change camera angle or shot size at least every few seconds; avoid two near-identical shots back to back.
5. Colour: pick the best-looking clip of each scene and match the others to it, so the ad has one look.
6. Product moment and CTA: hold long enough to read the offer.

## One timeline per hook
If the script has 3 hooks, export 3 versions: Hook 1 + body, Hook 2 + body, Hook 3 + body.

## Captions
| Choice | Pick |
|---|---|
| Style | Bold word-by-word / Clean subtitle / Highlight box / Other |
| Position | Lower third, above the platform's buttons |
| Case | UPPERCASE / Sentence case |
| Words to highlight | (brand name, offer, key benefit) |

Caption rules:
- Captions match the script word for word, including brand spelling.
- Numbers as digits on screen ("₹299", "3 days").
- Nothing hidden behind the platform's like / comment / share buttons.

## Checklist
- [ ] No black frames or tiny leftover pieces between cuts
- [ ] One colour look across all clips
- [ ] Captions checked against the script
- [ ] One export per hook
