# 5. Clip check (before editing)

Check every generated clip **before** editing starts. Fixing a clip now takes minutes; finding it after
the edit means redoing the edit.

## For each clip

| Clip | Words match script? | Brand words said right? | Doubled / extra words? | Black, flash or frozen frames? | Looks consistent? | Verdict |
|---|---|---|---|---|---|---|
| H1 | | | | | | Keep / Trim / Redo |
| B1 | | | | | | |

## What to check

**Words**
- Play the clip with the script open. Every word must match, in order.
- Listen for doubled words ("the the"), extra words the AI added, and cut-off endings.
- Brand and product names: compare with the pronunciation table in the brand sheet.

**Picture**
- Scrub frame by frame at the start and end: black frames, white flashes, frozen picture, a split-second of another shot.
- Faces, hands and the product: same look as in other clips? Label text readable and correct?

**Continuity**
- Same clothes, same place, same time of day as the clip before it.
- People looking in the right direction for the next cut.

## How to fix
1. **Trim** if the problem is at the start or end.
2. **Cut around it** if the line is still complete without it.
3. **Redo the clip** only when editing can't fix it. Add the problem to the AVOID line of the prompt first.

## Checklist
- [ ] Every clip has a verdict
- [ ] Every "Redo" has an updated prompt
- [ ] New problems added to the mistakes log
