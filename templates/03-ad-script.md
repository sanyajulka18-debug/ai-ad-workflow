# 3. Ad script

One fixed format for every script, so the prompts, clip check and captions can all be compared
against it word by word.

## Details
- **Brand:** (from the brand sheet)
- **Format:**
- **Target length:**  sec
- **Platform:** Reels / Shorts / TikTok / Meta feed

## Hooks (write 3, test them)
The first 3 seconds decide whether people keep watching. Each hook should work on its own with the same body.

```
[HOOK 1]
SPEAKER: line

[HOOK 2]
SPEAKER: line

[HOOK 3]
SPEAKER: line
```

## Body

```
[BODY]
SPEAKER: line
SPEAKER: line
(Visual: what we see during these lines)
```

## Call-to-action

```
[CTA]
SPEAKER: line
(On screen: offer text, exactly as approved)
```

## Writing rules
- One line = one sentence a person can say in one breath.
- Numbers written the way they're said ("five forty", not "540") if the AI voice must say them.
- Brand words spelled the way the brand sheet says.
- Only claims from the brand sheet's CAN column.

## Checklist
- [ ] 3 hooks, each under 3 seconds when read aloud
- [ ] Every line has a speaker
- [ ] Read aloud once with a timer: total length fits the target
- [ ] All claims checked against the brand sheet
